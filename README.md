# CySA+ CS0-003 Study Guide

An interactive practice quiz for the CompTIA CySA+ (CS0-003) exam, including scenario-based questions. Each question comes with an explanation, and you can choose how many questions to take and which study mode to use.

## Use it

Open the live version here: **https://huebrown89.github.io/cysa-study-guide/index.html

The guide is one self-contained file (`index.html`), so you can also download it and open it in any browser.
